# Love Calculator

Premium International Love Calculator — mobile-first, SEO-optimized, AdSense-ready.

## Deploy on GitHub Pages (FREE)

1. Create a new GitHub repository named `love-calculator`
2. Upload ALL files from this folder to the repository
3. Go to: Settings → Pages → Source → Deploy from branch → `main` → `/ (root)`
4. Your site will be live at: `https://YOURUSERNAME.github.io/love-calculator/`

That's it! Free hosting, unlimited visitors, HTTPS included.

## Features
- Name + thumbprint love calculation
- First-visit boost (98-100%)
- Light/Dark themes + 2 color palettes
- Past/Present/Future love timeline
- Share card (JPG) via native share sheet
- 8 AdSense ad slots
- SEO optimized (JSON-LD, FAQ schema, Open Graph)
- Full Unicode name support (any language, any script)
- Mobile, tablet, desktop responsive
